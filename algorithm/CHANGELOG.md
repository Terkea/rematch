# The algorithm changelog

One entry per algorithm version, newest first. The id is `algo-<version>+<hash>`: the version is for people, the hash is the first 12 hex characters of the sha256 of `manifest.json`'s canonical JSON, and it is the proof. `manifest.json` is generated by `cargo run -p cli -- algo manifest --write` and checked by `backend/crates/algo/tests/manifest.rs`; `scripts/algorithm/check.mjs` fails a pull request whose components changed without the bump below and an entry here (ADRs 0104 and 0105).

- Major: layer 1 to 3 output can change (a protocol, a constant, a detector, the ranking, the trainer or the focus rules). The replay goldens in `backend/fixtures/replay/` change with it, and the Tier 1 scorecard is rerun.
- Minor: only the language layer changes (a prompt file, a model id, the validator). The goldens stay as they are.
- Patch: no output changes (a refactor or a comment in a digested file). The goldens must be byte-identical, which is what proves it.

Each entry says what changed, why, the ADR, and the benchmark delta (the scorecard before and after; `cli bench compare` once it exists).

## algo-1.0.0+fd96e117c013

2026-11-24. The first named version: the algorithm as it stood on `main` at 0d1afa6, with nothing changed in its output.

- What it is: **Stockfish 19** (`sf_19`, the pinned `stockfish-linux-x86-64-universal` build) at 300,000 nodes per position, protocol `sf19-n300k-v1`, one thread and 16 MB of hash, `ucinewgame` before every search; enrichment `enr-v1` (MultiPV 3 at 300,000 nodes on at most 30 critical plies, threats at 50,000 nodes); the **Syzygy** 3-4-5 set; **Maia 2** (`maia2==0.11.0`, model `rapid`) when `MAIA_URL` is set; player game metrics v3; the timeline detector `tl-v1`; the ranking rule `rank-v1` (ADR 0101: an 80% range above the benchmark and at least 0.02 points a game, 30 games); coaching input `coaching-input-v3` and `weekly-input-v1`; the trainer `trainer-v1` (ADR 0090) and the focus `focus-v1` (ADR 0091); the prompt sets and the models `claude-sonnet-5-5` and `claude-haiku-5-5` (API `2026-10-21`). `manifest.json` holds every value and digest.
- What changed: nothing a replay can see. `Threads 1` and `Hash 16` are now sent to every engine instead of being left to **Stockfish**'s defaults, which are the same values; `backend/crates/engine/tests/uci_audit.rs` shows the evaluations are identical with and without them.
- Why: so every stored recommendation names the rules that produced it (ADR 0104).
- ADRs: 0104 (the four layers and the version policy), 0105 (the manifest, the stamping and the replay suite), 0101 (the ranking rule).
- Benchmark: the baseline. Tier 1 smoke suite at 12,000 nodes per search (`docs/benchmark.md`): recall at 2 60%, top-1 precision 60%, clean controls with a rank-1 weakness 0 of 1, 80% intervals holding the true rate 60% (20 intervals), drills that train the flaw 60%, mean games to a top-2 detection 45, same data same weaknesses yes, top-2 overlap without 10% of the games 100%.
