The roadmap is the [milestones on GitHub](https://github.com/Terkea/rematch/milestones). Each milestone has one epic per theme; the epic is a spec (the problem, the evidence, the design, the acceptance criteria) and its work is linked to it as sub-issues. This page is built from them, so the progress below is GitHub's{roadmap.source === "seed" ? The order follows one question: will this make a player better? It comes from a week of using it on my own account (824 rapid), ranked by what the [research on learning](/rematch/docs/research/2026-11-23-what-helps-amateurs-improve/) says should help. An idea becomes work in four steps: an issue, a spec the maintainer accepts (`accepted`), a milestone, then the pull requests that close it ([how we ship](/rematch/docs/sdlc/)).

## Open for contributors

Issues labelled [good first issue](https://github.com/Terkea/rematch/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) are small, with the files to start from; [help wanted](https://github.com/Terkea/rematch/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) issues are larger. Comment on one before you start, so two people don't build the same thing.

## Version 1.0

1.0.0 is reserved for the first complete release, the MVP, and is declared by the maintainer in its own decision record. The epic "What 1.0 means" in the v1.0 milestone proposes the bar. Until then every release is a 0.y.z beta.
