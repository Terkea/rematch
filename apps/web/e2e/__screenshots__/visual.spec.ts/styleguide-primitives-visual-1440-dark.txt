Primitives

Hover changes tone, never position: a surface steps along the tonal ladder, and a control that is already a well steps its edge. Focus is a 2px ink ring on every surface. Disabled drops to faint ink; only the primary button keeps a quiet well fill, so the main action keeps its place. The hover and focus cells are the components' own styles, forced on, not drawings of them.

Buttons

Destructive actions are ink-outlined with an explicit verb. A button has no error look: the field it submits carries the error, and red stays for mistakes.
