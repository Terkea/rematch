# 0002. Next.js (App Router) for the web app

Date: 2026-11-21
Status: Accepted

## Context

We need server-rendered landing and SEO pages, an app shell, and API routes.

## Decision

Next.js 16, React 19 and Tailwind 4, hosted on Vercel.

## Alternatives considered

Remix, SvelteKit, a Vite single-page app.

## Consequences

The largest ecosystem for premium UI work. Long-running work must stay out of the web tier.
