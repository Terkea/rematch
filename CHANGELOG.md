## Changelog

Rematch follows [Semantic Versioning](https://semver.org/). Every `0.y.z` release is a beta:
while the version starts with 0, a breaking change bumps the minor and a feature or fix bumps the
patch. `1.0.0` is reserved for the MVP and is a deliberate maintainer decision
([ADR 0095](docs/decisions/0095-open-source-sdlc-and-releases.md)). Entries below are written by
[release-please](https://github.com/googleapis/release-please) from the Conventional Commit
titles of merged pull requests.

## Unreleased / pre-history

Everything before 0.1.0 was built in a private repository and is not listed here release by
release. The [decision log](docs/decisions/README.md) records what was built and why, one ADR per
decision, and the full commit history is kept in this repository.
